# 台海内战：玩法与剧情设计文档

## 一、章节定位

**章节名称**：第三章：台海内战

**时间跨度**：2022年夏~秋（10~15 tick）

**核心张力**：**“你赢了每一场战斗，但你可能输掉整场战争。”**

**核心情绪**：**从“克制”到“失控”**——玩家在前夕阶段“刹车”了很多次。现在，“刹车”没了。战争有自己的逻辑。

**玩家身份**：建制派（执政派系）。如果前夕阶段建制派影响力下降（民族派上升），本章开场会有“军方不信任”的暗示。

**章节结构**：

```
第一幕：开战（3~5 tick）——“我们准备好了”
  → 第二幕：升级（3~5 tick）——“打得更狠一点”
    → 第三幕：收束（4~5 tick）——“什么时候停”
```

**表现方式**：超事件（全屏黑底 + 音乐 + 强制暂停）

**演出**：

> **标题**：台海内战
>
> **副标题**：2022年，夏。海峡。
>

> 你问：“准备好什么？”

**每 tick 3~4 个行动点**。四条线不能全要。玩家要取舍。

### 3.2 四条线的核心指标

| 线       | 指标       | 初始值            | 说明                                |
| -------- | ---------- | ----------------- | ----------------------------------- |
| **军事** | 军事分数   | +15               | 海峡控制+对岸节点占领-我军损失      |
| **政治** | 战争支持度 | 民心×0.8          | <30 触发反战运动，<15 触发政局动荡  |
| **外交** | 国际支持度 | 前夕国际影响力-20 | <0 有暗中支持，<-30 制裁，<-60 干预 |
| **后勤** | 后勤承受力 | 军备×0.7+经济×0.3 | <30 军事效果减半，<15 军备枯竭      |

**战争总分** = 军事×40% + (战争支持度-50)×20% + 国际支持度×20% + 后勤×20%

### 3.3 第一 tick 关键事件：海峡通道战斗

**表现方式**：沉浸式（立绘 + 对话 + 背景）

**演出**：

> **背景**：指挥部。大屏幕上显示海峡通道态势图。我军舰队与对岸舰队在通道两端对峙。
>
> **立绘**：将军（左，军装，表情严肃）。
>
> 将军：“海峡通道，宽度3。双方舰队已经进入。”
> 你问：“战力对比？”
> 将军：“我方略优。但如果日本介入，会变成劣势。”
> 你问：“日本会介入吗？”
> 将军沉默了一会儿。他说：“看我们打得多快。”
> 旁白：“打得多快。你‘记住’了这三个字。”
>
> **选项**（`main_choice`）：
>
> - A：“集中兵力，快速突破” → 军事分数+10、但后勤消耗+15、日本介入风险+20%
> - B：“稳步推进，保存实力” → 军事分数+5、后勤消耗+5、日本介入风险+5%
> - C：“先发制人，打击日本舰队” → 军事分数+5、中日冲突风险+50%、国际支持度-15
> - D：“（沉默）” → 将军自行决定“稳步推进”。无额外效果。

### 3.4 关键事件：母亲的医院（战时变体）

**触发条件**：第一幕第二 tick 自动触发。

> 孩子（电话那头）：“妈妈，爸爸‘说’他‘可能’要‘去’‘前线’。”
> 母亲沉默了很久。她说：“……你爸‘不是’军人。”
> 孩子：“但‘工厂’‘转产’了。‘军工’‘需要’‘人’。”

>
> **选项**：
>
> - A：“给前线医护人员发双倍补贴” → 国库-15、战争支持度+5、医疗+5
> - B：“号召‘坚持’” → 战争支持度-3、基层疲劳+10
> - C：“（沉默）” → 战争支持度-5

## 四、第二幕：升级（3~5 tick）

### 4.1 核心玩法：升级决策

**表现方式**：沉浸式（立绘 + 对话）

**触发条件**：第二幕第一 tick。

**演出**：

> **背景**：指挥部。大屏幕上的态势图更新了。我军占领了海峡通道。对岸舰队退守。
>
> **立绘**：将军（左，表情比之前更严肃）。
>
> 将军：“海峡通道‘控制’了。对岸舰队‘退守’了。我们‘可以’‘选择’。”
> 你问：“‘选择’‘什么’？”
> 他说：“‘升级’或‘不升级’。”
> 你问：“‘升级’‘什么’？”
> 他说：“打击对岸‘军事基地’。或者……‘基础设施’。”
> 你问：“‘基础设施’？”
> 他沉默了一会儿。他说：“‘基础设施’‘包括’‘电厂’、‘水厂’、‘通信’‘枢纽’。打击‘这些’，会‘让’‘对岸’‘瘫痪’。但‘平民’‘伤亡’‘会’‘上升’。”
> 旁白：“‘平民’‘伤亡’‘会’‘上升’。他‘说’这句话的时候，‘没有’‘看’‘你’。”
>
> **选项**（`main_choice`，核心节点）：
>
> - A：“升级——打击军事基地” → 军事分数+10、国际谴责+15、平民伤亡低
> - B：“再升级——打击基础设施” → 军事分数+15、国际谴责+25、平民伤亡高
> - C：“不升级，保持有限战争” → 军事分数+5、民族派-10（“软弱”）
> - D：“（沉默）” → 将军“自行决定”打击军事基地。军事分数+8、国际谴责+10

### 4.2 关键事件：反战运动

**表现方式**：事件（标题 + 内容 + 选项按钮）

**触发条件**：战争支持度 < 30。

**演出**：

> **标题**：反战运动
>
> **内容**：
> 新闻：“多地爆发‘反战’示威。示威者说：‘我们要和平，不要战争。’”
> 民族派说：“这是‘叛国’。”
> 改革派说：“这是‘民意’。”
> 你看着新闻。示威者里有年轻人，有老人，有抱着孩子的母亲。他们举着牌子：“停止战争。”
> 旁白：“他们‘说’‘停止战争’。你‘也’‘想’‘停止’。但‘你’‘不知道’‘怎么’‘停’。”
>
> **选项**：
>
> - A：“镇压” → 战争支持度+5、民心-15、后续“信任危机”
> - B：“对话” → 战争支持度-5、但民心+10、民族派-10（“软弱”）
> - C：“（沉默）” → 反战运动扩大、战争支持度-10/tick

### 4.3 关键事件：日本介入升级

**表现方式**：沉浸式（立绘 + 对话）

**触发条件**：日本介入风险 > 50，或第二幕第二 tick。

**演出**：

> **背景**：指挥部。大屏幕上的态势图更新了。东海方向出现日本舰队图标。
>
> **立绘**：情报主管（左，表情紧张）。
>
> 情报主管：“日本海上自卫队‘护航’范围扩大到‘海峡中线’以东。”
> 你问：“他们‘想’‘干什么’？”
> 他说：“他们‘想’‘试探’我们的‘底线’。”
> 你问：“我们‘怎么办’？”
> 他说：“‘拦截’是‘中日冲突’。‘放行’是‘默认日本介入’。”
> 旁白：“‘拦截’或‘放行’。你‘选’一个。你‘选’的时候，‘想’起‘前夕’阶段‘刹车’了‘很多’次。现在，‘刹车’‘没了’。”
>
> **选项**（`main_choice`）：
>
> - A：“拦截” → 中日冲突风险+30%、民族派+15、战争支持度+5
> - B：“放行” → 日本介入更深、国际支持度-10、战争支持度-5
> - C：“（沉默）” → 日本“默认”介入合法化。无额外效果。

### 4.4 关键事件：父亲的来信

>

> 旁白：“他‘说’‘他’‘不’‘知道’。你‘也’‘不’‘知道’。你‘只’‘知道’，他‘在’‘前线’。”
>
> [确定]

**效果**：民心-3，战争支持度-3（“父亲的信”让玩家“感受到”战争的“代价”）。

## 五、第三幕：收束（4~5 tick）

### 5.1 核心玩法：停火决策

**表现方式**：沉浸式（立绘 + 对话）

**触发条件**：第三幕第一 tick，战争总分在 -10~+40 之间。

**演出**：

> **背景**：指挥部。大屏幕上的态势图“凝固”了。双方都在“等”。
>
> **立绘**：将军（左，表情疲惫）。
>
> 将军：“我们‘可以’‘停’了。”
> 你问：“‘停’？”
> 他说：“‘停火’。‘谈判’。‘结束’。”
> 你问：“‘结束’‘之后’‘呢’？”
> 他说：“‘之后’‘是’‘政治’。”
> 旁白：“‘政治’。你‘想起’‘前夕’阶段‘刹车’了‘很多’次。现在，‘刹车’‘回来’了。但‘这次’，‘刹车’‘不是’‘免费’的。”
>
> **选项**（`main_choice`，核心节点）：
>
> - A：“停火，开始谈判” → 战争结束，进入“结果判定”
> - B：“继续打，直到彻底胜利” → 战争继续，军事分数+10、但后勤承受力-15、战争支持度-10
> - C：“（沉默）” → 将军“自行决定”继续打。军事分数+5、后勤承受力-10

### 5.2 关键事件：孩子的信

**表现方式**：事件（标题 + 内容 + 确定按钮）

**触发条件**：第三幕第二 tick，自动触发。

**演出**：

> **标题**：孩子的信
>
> **内容**：
> 孩子写信给你。信上写着：
> “爸爸，‘我’‘在’‘电视’‘上’‘看到’‘打仗’了。‘很’‘可怕’。‘我’‘不’‘想’‘让’‘你’‘去’‘打仗’。‘但’‘我’‘知道’‘你’‘不’‘是’‘军人’。‘我’‘写’‘这’‘封’‘信’‘的’‘时候’，‘妈妈’‘在’‘医院’‘里’。‘她’‘说’‘她’‘很’‘忙’。‘我’‘不’‘知道’‘她’‘什么’‘时候’‘回’‘来’。”
> 旁白：“孩子‘写’了。你‘读’了。你‘想’‘回’‘信’。但‘你’‘不’‘知道’‘写’‘什么’。”
>
> [确定]

**效果**：战争支持度-5，民心-3。

### 5.3 战争结果判定

**表现方式**：超事件（全屏黑底 + 音乐 + 强制暂停）

**音乐**：根据结果不同，音乐不同。胜利=沉重的弦乐（不是欢快的）；惨胜=疲惫的钢琴；僵持=低沉的鼓点；失败=沉默。

**演出**（以“惨胜”为例）：

> **标题**：停火
>
> **副标题**：2022年，秋。海峡。
>
> **正文**：
> 停火了。战争结束了。双方都“打”不动了。
> 你站在指挥部。将军说：“我们‘赢’了。但‘赢’得‘不’‘干净’。”
> 你问：“‘不’‘干净’是‘什么’‘意思’？”
> 他说：“意思是‘我们’‘控制’了‘海峡’。但‘我们’‘也’‘死’了‘很多’‘人’。”
> 旁白：“你‘赢’了。但‘赢’的‘代价’，你‘知道’。”
>
> [按钮：继续]

**结果判定**：

| 战争总分 | 结果         | 后续                                                  |
| -------- | ------------ | ----------------------------------------------------- |
| > 40     | **大获全胜** | 直接进入凯旋线                                        |
| 10~40    | **惨胜**     | 进入“稳定政局”玩法                                    |
| -10~10   | **僵持**     | 进入“不输不赢”结局（不触发凯旋线，也不触发丢人现眼）  |
| -40~-10  | **惨败**     | 进入“丢人现眼”（台海未统一，无debuff）                |
| < -40    | **彻底失败** | 进入“丢人现眼”（台海未统一，`humiliation_level`最高） |

## 七、建制派在“台海内战”的叙事线

### 7.1 建制派的“自信”

**第一幕**：海峡通道“控制”了。建制派“觉得”自己“做对了”——军备建设“有用”，外交“有效”。

**叙事节点**：

- 超事件“台海内战”：“你签了作战命令。笔很轻。”
- 海峡通道战斗：“集中兵力，快速突破”。建制派“选择”了“快”。
- 母亲的医院（战时）：“给前线医护人员发双倍补贴”。建制派“选择”了“支持”。

### 7.2 建制派的“动摇”

**第二幕**：升级决策。建制派“知道”自己在“打得更狠”。但“不知道”“狠”的“尽头”是“什么”。

**叙事节点**：

- 升级决策：“打击基础设施”或“不升级”。建制派“选择”了“狠”或“克制”。
- 反战运动：“镇压”或“对话”。建制派“选择”了“压”或“听”。
- 父亲的来信：“他不知道他什么时候会哭。”建制派“读”了信，“不知道”该“说什么”。

### 7.3 建制派的“收束”

**第三幕**：停火决策。建制派“知道”战争“该停”了。但“不知道”“停”了“之后”会“怎样”。

**叙事节点**：

- 停火决策：“停火，开始谈判”。建制派“选择”了“停”。
- 孩子的信：“爸爸，我不想让你去打仗。”建制派“读”了信，“不知道”该“写”什么“回信”。
- 超事件“停火”：“你赢了。但赢的代价，你知道。”

### 7.4 建制派的“核心叙事**

**“我们打了仗。我们赢了。但赢的代价，我们不知道值不值。”**

## 八、和后续章节的衔接

**台海内战结束时**：

- `war_result` 决定进入哪个分支（凯旋线/稳定政局/丢人现眼）。
- `escalation` 决定“惨胜”的“程度”（升级越多，惨胜的debuff越重）。
- `father_frontline` 和 `anti_war_movement` 影响后续副线走向。

**进入第四章（内战结束）**：

- 超事件“停火” → 点击继续 → 进入第四章。
- 第四章开场：根据 `war_result` 不同，开场不同。
  - 大获全胜：沉浸式（“你站在指挥部。将军说：‘我们赢了。’”）
  - 惨胜：超事件“惨胜”（“你赢了。但赢得不干净。”）→ 进入“稳定政局”玩法。
  - 丢人现眼：超事件“丢人现眼”（“你输了。你签了停战协议。笔很轻。”）→ 进入“军管”玩法。

## 九、一句话总结

**台海内战 = 三幕式（开战→升级→收束）+ 战争管理（军事/政治/外交/后勤四线）+ 每 tick 3~4 个行动点 + 四条线不能全要 + 关键事件（海峡通道/母亲医院/父亲决定/反战运动/日本介入/父亲来信/停火决策/孩子信）+ 超事件（台海内战/停火）。** 核心张力是**“你赢了每一场战斗，但你可能输掉整场战争”**。建制派的叙事线是**“自信→动摇→收束”**——玩家“打了仗”，“赢了”，但“赢”的代价，“不知道值不值”。**“你签了作战命令。笔很轻。但战争不是‘笔’能决定的。”**
