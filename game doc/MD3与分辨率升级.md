# MD3 风格 UI + 2 倍分辨率升级（t89）

队长裁决（2026-10-31）：UI 参照 Google Material Design 3 重做；画布分辨率翻 4 倍（1 像素 → 2x2 像素，即 960x540 → 1920x1080），文字与图形更清晰，保留轻微像素边缘但不刺眼。整体定位：HOI4 简化版、偏剧情向。

## 一、分辨率 2x
- 画布 1920x1080；世界坐标整体 x2（所有 UI 常量、字号、点击区），游戏逻辑（引擎 st2、tick、事件）不变。
- 地图地块几何同步 x2（mapTableOf 的坐标）。
- 字体保持 Maple Mono Normal CN 三字重，字号 x2 后更锐利。

## 二、MD3 风格
- 色板：MD3 tonal palette（Surface Container / Surface Container High / Primary / OnSurface / OnSurfaceVariant / Outline / Error）。深色主题（Dark scheme）。
- 圆角：按钮/卡片/面板统一较大圆角（MD3 shapes；chip 全圆角，卡片 12-16dp，对话框 28dp——按 2x 后等效）。
- 顶栏：MD3 Top App Bar 风格 — 国家主标题 + 派系副标题 + 日期 + 资源 chips。
- 底栏：MD3 Navigation Bar — 4 个按钮带图标+文字，选中态高亮（当前只有文字按钮，太单调）。
- 事件卡：MD3 Dialog/Card — 标题、内容、选项为 MD3 Button（filled / tonal 混排），不再是「· 」纯文本。
- 沉浸式/超事件：MD3 全屏对话框风格，黑底逐行保留。
- 状态层（state layer）：按下/悬停时的 8-12% 覆盖色（简化：按下即闪一下覆盖色）。
- 阴影/层级：z 分层已有，面板用 Surface Container High 与背景拉开。

## 三、保留约束
- 进游戏先看地图（操作面板不自动开，点底栏「操作」开）——HOI4 式。
- 按钮文本居中（已做，迁移到新坐标）。
- 本体零剧情文案；全部视觉框架本体提供，文案/图标 id 由模组 entities.ui 配。
- 缺图占位保留；音乐挂载点缺失静默。

## 四、验收
- node test/smoke.js 全绿（坐标 x2 后同步改写驱动脚本；tick 驱动每 tick 先点「操作」按钮开面板）。
- node test/browser-check.js 全绿 + 新截图。
- gen-mods 重跑确认 bake 不变。

## 五、不做
- 不改 engine.subl 的六段 tick 循环语义。
- 不加真实图片资产（缺图占位即可）。
- 不做动画过渡（KAPLAY 可后补）。

## 六、追加裁决（2026-10-31 晚）

### 6.1 底栏按钮 = 全屏界面切换（不是侧面板）
- 点底栏「操作/国策/国家属性/控制地块」=> 切换到对应**全屏界面**（MD3 风格页面，覆盖整个画布），不再是当前右侧小面板。
- 每个全屏界面右上角（或左上角，MD3 惯例）提供「返回游戏 / 返回地图」按钮，点击回到地图主界面。
- 游戏主界面 = 地图地块（玩家点击地块选中、相机缩放平移），即队长之前要求做的地图。
- 操作阶段（ops）若开着操作页，点其他底栏按钮同样切全屏；回来时保持操作状态。
- 事件卡/沉浸式/超事件仍然盖在当前界面之上（z 更高），不变。

### 6.2 清晰度最高优先
- 「真的太糊」是当前最大痛点：1920x1080 画布必须做实，且窗口适配缩放尽量整数倍。
- gameStartFit 的拉伸方式核对：渲染分辨率 ≥ 显示分辨率，避免画布被放大模糊。
- 字体渲染开线性过滤（CJK 图集已分桶），像素边缘保留在地块/图形，文字必须锐利。
