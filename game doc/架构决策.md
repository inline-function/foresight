## tick 循环（玩家钦定六段流程）

```
1. tick 开始：顶栏年月推进 + 资源产出结算（政治点/科技点/国库）+ 状态自然变化（疫情/经济/民心等）
2. 玩家操作阶段：行动点 2~4 个；底栏操作面板每项消耗 1 行动点；可“不操作”（跳过，行动点浪费）；行动点用完 → 自动进入结算
3. 事件触发阶段：tick 序数触发 / 条件触发 / 副线触发（每 3~4 tick），按优先级弹出（事件/沉浸式/超事件）
4. 玩家处理事件：事件点选项/确定；沉浸式看完对话点继续；超事件看完演出点继续
5. 结算阶段：应用事件效果（flag/资源/状态）；检查章末条件（tick 预算用完 → 章末结算）
6. 进入下一 tick
```

回合制而非实时钟——触发条件大量依赖 tick 序数，要求确定性。

## UI 归属

- **统一为底栏**：剧情设计里的“左侧栏操作弹窗”= 底栏「基本政策」面板按章节切换内容（疫情章=封控/刺激/舆论…，战争章=军事/政治/外交/后勤四线）。不另做左侧栏。
- 顶栏：国家主标题（全不透明）+ 派系副标题（弱透明）+ 右侧时间（年月，无回合数）。

## 数据与逻辑分层

- **视图用 JSON 表示**（章节/幕/事件/场景/面板/选项，全数据驱动）；
- **逻辑用 subs 写**（模组 `logic/*.subl`，t84 的 sublEval/sublRun 落地后接通）；
- **数据存储由深谋远虑本体提供 API**：持久化模组提供的 JSON（浏览器 localStorage，安卓端后补），经 `__subl.call` 桥暴露给 subs。

## 底栏四面板最终定义（2026-10-31 玩家定）

| 面板 | 内容 | 模组权限 |
|---|---|---|
| **国家属性** | 政治点、科技点、国库（资源型数值，含每 tick 产出） | 模组可定义属性条目与初始值 |
| **国策** | 国策树（解锁/前置）——**模组可增改国策树，这是作为模组加载器的核心功能** | 必须完全数据驱动 |
| **操作** | 模组提供图标按钮，点击进入对应操作页面（如疫情章的封控/刺激/舆论/医疗/动员/国际六组 radio 组） | 模组提供按钮与页面内容 |
| **控制地块** | 地块列表（命名/归属） | 同 t85 现状 |

- 原 t85 的「基本政策（开关型）」由「操作」页面承载（radio 组比单开关更通用；开关视作双值 radio）。
- 操作页面头部显示当前章的状态条（如疫情章：疫情严重度档位、医疗资源、财政、行动点余量）。
- 国家属性面板与操作页面头部不重复：属性面板=全局资源总览，操作页头部=本操作相关的即时状态。
