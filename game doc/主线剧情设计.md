# 深谋远虑·主线剧情设计（玩家与团队共撰，369 版）

## 结构总览

```
序章（超事件「2019年的冬天」）→ 第一章 疫情时期（15~20 tick）
  → 第二章 内战前夕（20~25 tick，三幕：恢复/变强/逼近）
    → 第三章 台海内战（10~15 tick，三幕：开战/升级/收束）
      → 第四章 内战结束（文档未给，待补：凯旋线/稳定政局/丢人现眼三分支）
```

## 序章：超事件「2019年的冬天」

全屏黑底+低沉弦乐+强制暂停。标题「2019年的冬天」副标题「一切还没有开始。一切已经在开始。」
正文要点：2019年12月武汉不明原因肺炎；简报第一页「病例数27，死亡率未知，传播途径未知」；第二页空白；秘书转专家「可能比非典严重」「现在不准备以后就不用准备了」；玩家签《疫情防控应急预案》；街上没人戴口罩；旁白「你准备了的东西和来了的东西，不是同一种东西」。

## 第一章：疫情时期

章节开场=沉浸式会议室（卫生部长vs财政部长：封城救经济之争；玩家「让我想想」）。每 tick：左侧栏操作（消耗行动点）→ 事件触发 → 副线场景 → 资源结算 → 下一 tick。

### 疫情操作弹窗
- 封控力度：精准防控/局部封控/全面封控/不封
- 经济刺激：大规模/精准滴灌/不刺激
- 舆论引导：公开透明/适度淡化/统一口径
- 状态条：疫情严重度（隐藏精确值）、医疗资源、财政(+20/tick)、行动点2/3

### 关键事件

1. **父亲的电话**（事件）触发=stimulus已设定。父亲工厂订单减少「我们这些工人还算不算人民？」选项：保企业不裁员(国库-15民心+10)/让市场决定(民心-15经济效率+5)/沉默(民心-10)。
2. **母亲的医院**（沉浸式）触发=lockdown≠不封 且 医疗资源<50。母亲护士、电话里与孩子「快了」。选项：补贴轮休(国库-15医疗+5民心+5)/号召坚持(医疗-5基层疲劳+10)/沉默(医疗-10)。
3. **爷爷的邻居**（事件）触发=communication≠公开透明 且 疫情>40。老李死于「不敢去医院」。选项：公开问题(民心+10医疗挤兑风险+20)/内部处理(民心-5稳定+5)/沉默(民心-10)。
4. **孩子的作文**（沉浸式）触发=tick12~15 且 taiwan_strait_status已设定。作文「我希望我爸爸不用去打仗」「因为工厂在造武器」。选项：不会打仗(民心+5，战争触发时信任-20)/准备是为了不打仗(民心+3)/沉默(民心-5)。
5. **副线·饭桌** 每3~4 tick自动插入，读 lockdown/stimulus/factory 生成变体。
6. **建制派动摇**（事件）触发=疫情>60或民心<50。「会议室里的沉默」。
7. **建制派代价**（事件）章末评价=失败/崩溃时：信任危机，建制派-10民族派+5。

### 章末防疫评价
| 条件 | 评价 | 音乐 | 效果 |
|---|---|---|---|
| 疫情<30 且 民心>70 | 优秀 | 温暖钢琴 | 阶段2资源+20% |
| 疫情<60 且 民心>50 | 合格 | 平稳弦乐 | 正常 |
| 疫情>60 或 民心<40 | 失败 | 低沉鼓点 | 稳定-20民心-15 |
| 疫情>80 或 经济<15 | 崩溃 | 沉重弦乐 | 提前结局「社会崩溃」 |

旗标：lockdown/stimulus/communication/factory/medical_support/neighbor_death/child_essay/pandemic_rating。

## 第二章：内战前夕（三幕）

开场超事件「账单」（低沉钢琴）：财政赤字、基层疲劳、民心未复。情绪=不安的平静。

### 第一幕 恢复（7~8 tick）
- 经济操作：基建投资(经济+20/财政压力+20/民心+5/军备+5)、消费刺激(经济+10/压力+10/民心+15)、出口导向(经济+15/压力+5/国际依赖+20)；财政整顿：加税(+15/tick民心-10稳定-5)、发债(+10/tick,债务危机风险)、削减开支(+8/tick民心-5稳定-3)。
- 事件：复工(父亲变体：稳岗补贴国库-20民心+10/让市场调节民心-10经济+5/沉默-5)；母亲医院变体(心理疏导国库-10民心+5医疗+5/不处理-5/沉默)；副线爷爷的公园；收束事件「恢复」。

### 第二幕 变强（7~8 tick）
- 超事件**美国分裂**（读世界旗标 usa_civil_war==split）：趁机扩大影响力(外交+15中美-20,east_asia_bloc=true)/保持战略定力(民族派-15)/沉默(民族派-10)。
- 军事操作：大幅增加军费(军备+25经济-10国际紧张+15)/适度(+10,-5,+5)/暂缓(-5经济+10)；军备方向：海军优先(海峡通道战力+15)/空军(制空+15)/陆军(登陆+15)。
- 科技操作：AI数字经济(科技+20军备-5经济+10)/高端制造军工(科技+10军备+15经济+5)/均衡(+8,+8,+8)。
- 事件：父亲工厂转产(「准备不是为了打仗是为了不打仗」民心+5/「该打就打」民族派+10民心-5/沉默)；副线孩子的防空演习；收束「变强」。

### 第三幕 逼近（7~9 tick）
- 外交操作：两岸关系（和平统一外交+10民族派-15,status peaceful，触发概率降/维持现状status_quo/强硬回应外交-15民族派+15,status tense概率升）；对日外交（警告-20介入风险-15%/搁置争议+10,+10%/不回应）。
- 超事件**对岸修宪**（east_asia_militarization>70 且 status≠peaceful）。
- 沉浸式**海峡对峙**：克制交涉(民族派-20挑衅+30%)/对等回应(擦枪走火+50%)/全面备战进战争前夜/沉默(军方自行+30%)。
- 事件：孩子作文变体；收束超事件**战争前夜**「你签了作战命令。笔很轻。」

旗标：recovery/military_buildup/tech_focus/east_asia_bloc/taiwan_strait_status/strait_incident/father_concern/child_essay。

## 第三章：台海内战（三幕）

开场超事件「台海内战」（《当那一天来临》式心跳鼓点。注：两版结果表冲突，待玩家裁决，见下）。

### 四线指标
军事分数(海峡控制+对岸节点占领-我军损失，初+15)；战争支持度(民心×0.8，<30反战运动<15政局动荡)；国际支持度(前夕国际影响力-20，<0暗中支持<-30制裁<-60干预)；后勤承受力(军备×0.7+经济×0.3，<30军事减半<15军备枯竭)。

战争总分 = 军事×40% + (战争支持度-50)×20% + 国际支持度×20% + 后勤×20%。每 tick 行动点 3~4，四线不能全要。

### 第一幕 开战（3~5 tick）
- 沉浸式**海峡通道战斗**：集中突破(军事+10后勤消耗+15日本介入风险+20%)/稳步推进(+5,+5,+5%)/先发制人打日本舰队(+5,中日冲突+50%,国际-15)/沉默(将军稳步)。
- 母亲医院战时变体(双倍补贴国库-15支持+5医疗+5/号召坚持支持-3疲劳+10/沉默支持-5)。
- 副线父亲的决定(劝他留下民心+5特殊对待/尊重选择民心+3父亲去前线/沉默father_frontline=silent)。
- 收束「第一周」。

### 第二幕 升级（3~5 tick）
- 沉浸式**升级决策**：打击军事基地(军事+10谴责+15平民低)/打击基础设施(军事+15谴责+25平民高)/不升级有限战争(军事+5民族派-10)/沉默(将军自行军事+8谴责+10)。
- 事件反战运动(支持度<30)：镇压(支持+5民心-15信任危机)/对话(支持-5民心+10民族派-10)/沉默(扩大-10/tick)。
- 沉浸式日本介入升级(风险>50)：拦截(中日冲突+30%民族派+15支持+5)/放行(介入更深国际-10支持-5)/沉默。
- 事件父亲的来信(民心-3支持-3)。
- 收束「升级」。

### 第三幕 收束（4~5 tick）
- 沉浸式**停火决策**：停火谈判(进结果判定)/继续打彻底胜利(军事+10后勤-15支持-10)/沉默(将军继续军事+5后勤-10)。
- 事件孩子的信(支持-5民心-3)。
- 超事件**停火**+结果判定。

### 结果判定（两组表冲突，待裁决）
A 版（五档）：>40大获全胜(凯旋线)；10~40惨胜(稳定政局)；-10~10僵持(不输不赢结局)；-40~-10惨败(丢人现眼)；<-40彻底失败(humiliation_level最高)。
B 版（三档）：>40大获全胜；10~40惨胜；<40失败(丢人现眼)。

旗标：strait_battle/escalation/japan_intervention/father_frontline/anti_war_movement/war_result。
